# نظم داد — Nazm Dad

**A Constitutional Framework for Iran**

نظم داد یک پروژه مستقل طراحی قانون اساسی برای ایران است که بر توزیع قدرت، حکومت قانون، حقوق بنیادین، خودگردانی سرزمینی و سازوکارهای ضدبن‌بست تمرکز دارد.

## اصول بنیادین
- تفکیک قدرت
- مهار متقابل
- چندمرکزی
- وحدت در قانون

## وضعیت
- وب‌سایت: `v0.1-site`
- قانون اساسی: نسخه ۰.۵ قفل‌شده
- `docs/0.4.md` و `docs/0.5.md`: در انتظار درج متن authoritative کامل
